Every template lives in a single folder under `registry/templates/<id>/`:

```txt
registry/templates/<id>/
  template.tsx   # Zod schema, sample payload, and Satori JSX render function
  meta.json      # Metadata, tags, and optional contrast color pairs
  preview.png    # Generated by npm run preview:build (1200x630 PNG)
```

Keep everything under `registry/` self-contained: templates and runtime helpers must **not** import from `app/` or root website config modules.

## Template contract

Use `defineTemplate` from `../../lib/define-template`:

```tsx
import { z } from "zod";
import { defineTemplate } from "../../lib/define-template";

export const params = z.object({
  title: z.string().min(1).max(80),
  subtitle: z.string().max(140).default(""),
  accentColor: z
    .string()
    .max(7)
    .regex(/^#[0-9a-fA-F]{6}$/)
    .default("#38bdf8"),
});

export default defineTemplate({
  id: "my-card",
  name: "My Card",
  description: "Short one-line description for the gallery and registry.",
  params,
  sample: {
    title: "Hello from Ogami",
    subtitle: "Declarative Open Graph images with strict parameter caps.",
    accentColor: "#38bdf8",
  },
  render: (p, ctx) => {
    const fittedTitle = ctx.autoFit(p.title, {
      maxWidth: 960,
      maxLines: 2,
      maxFontSize: 64,
      minFontSize: 32,
      lineHeight: 1.15,
    });
    const fontFamily = Array.from(new Set(ctx.fonts.map((f) => f.name))).join(", ");

    return (
      <div
        style={{
          display: "flex",
          flexDirection: "column",
          width: "100%",
          height: "100%",
          padding: 56,
          backgroundColor: "#09090b",
          color: "#fafafa",
          fontFamily,
        }}
      >
        <div
          style={{
            display: "flex",
            fontSize: fittedTitle.fontSize,
            fontWeight: 700,
            lineHeight: fittedTitle.lineHeight,
          }}
        >
          {p.title}
        </div>
      </div>
    );
  },
});
```

## Validation rules enforced automatically

`defineTemplate` and the test suite enforce:

1. **Matching kebab-case `id`:** `id` must match the folder name (`registry/templates/<id>`).
2. **Length-capped strings:** Every `z.string()` parameter (including optional, default, or nested fields) must specify a finite positive `.max(n)`.
3. **Valid non-negative safe integers:** Numeric metrics use `nonNegativeSafeIntParam` from `../../lib/format-number` (`0` through `Number.MAX_SAFE_INTEGER`) so `NaN`, `Infinity`, decimals, and negative inputs return HTTP `400`.
4. **Number formatting consistency:** New milestone templates use `formatNumber(value, p.format)` from `../../lib/format-number` (`"compact"` default or `"exact"` `en-US` digit grouping). (`github-repo` keeps plain `en-US` digit grouping via `Intl.NumberFormat("en-US")`.)
5. **Safe `sample` data:** `sample` must pass `params.safeParse` and contain only base-supported scripts (Latin or Cyrillic).
6. **Original designs only:** Do not include trademarked logos or copy external products' designs. Stick to original layouts and simple inline geometric SVGs.

## `meta.json` and contrast pairs

Include `meta.json` with `id`, `name`, `description`, `author`, `tags`, `version`, and optional `colors` entries checked by the [Playground](/playground):

```json
{
  "id": "my-card",
  "name": "My Card",
  "description": "Short one-line description for the gallery and registry.",
  "author": "Your Name",
  "tags": ["minimal", "dark"],
  "version": "1.0.0",
  "colors": [
    {
      "label": "Title on card",
      "foreground": "#fafafa",
      "background": "#09090b",
      "largeText": true
    },
    {
      "label": "Accent on card",
      "foreground": "#38bdf8",
      "background": "#09090b",
      "largeText": true,
      "foregroundParam": "accentColor"
    }
  ]
}
```

When `colors` includes `foregroundParam` or `backgroundParam`, the playground checks contrast dynamically against the live color input. If a template omits `colors`, the contrast panel reports that no pairs were declared.

## Register, generate previews, and verify

1. Export the template in `registry/templates/index.ts`.
2. Add its static `preview.png` import to `app/_lib/template-previews.ts`.
3. Generate previews and rebuild `public/r/*.json`:

```bash
npm run preview:build
npm run registry:build
npm test
npm run lint
npm run build
```

See [Satori Rules](/docs/satori-rules) for supported layout patterns before designing your JSX.
